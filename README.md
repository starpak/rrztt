# 若若子官网 · rrztt.site

> 一个还在练习唱歌、努力不冷场的个人势 VUP 的官方网站。

本仓库由原始设计稿（压缩包）还原为完整的静态 HTML 网站，并在此基础上做了**动画夸张化**处理、加入了**加载动画**等标准网站流程。

## 功能特性

- **加载动画**：开场 Loader（旋转光环 + 逐字标题 + 进度条），加载完成后内容揭幕浮起。
- **夸张动画**：
  - 首页主标题逐字弹入；
  - 立绘悬浮 + 光环呼吸 + 悬停放大旋转；
  - 标签悬停 3D 抬升、渐变高光、文字反白；
  - 导航链接下划线生长、Logo 抖动；
  - 跑马灯横幅、背景浮动光斑。
- **标准网站流程**：
  - IntersectionObserver 驱动的滚动揭示（多方向变体）；
  - 平滑滚动、当前页导航高亮；
  - 页面切换淡出过渡；
  - 回到顶部按钮；
  - 尊重 `prefers-reduced-motion`。
- **技术栈**：原生 HTML/CSS/JS + Tailwind CSS（浏览器 CDN 构建）+ Lucide 图标，无需构建步骤。

## 本地预览

无需安装依赖，直接用浏览器打开 `index.html` 即可。推荐起一个本地静态服务器：

```bash
# 任选其一
python3 -m http.server 5173
# 或
npx serve .
```

然后访问 `http://localhost:5173`。
