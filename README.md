## ✨ 功能特性

### 🎨 Cel Shading 风格设计
- **配色方案**：米白色背景 (#fafaf5) + 深黑前景 (#1a1a2e) + 鲜艳强调色
- **方角设计**：所有组件采用硬朗直角 (rounded: 0)
- **粗边框**：统一 3px 粗边框
- **硬阴影**：无模糊的硬阴影效果 (3px 3px 0)
- **快速过渡**：100ms 动画时序，响应更敏捷
- **大号粗体字**：font-black uppercase

### 🎭 动画效果
- **加载动画**：开场 Loader（左侧竖向进度条 + 百分比同步）
- **夸张动画**：
  - 首页主标题逐字弹入；
  - 立绘悬浮 + 光环呼吸 + 悬停放大旋转；
  - 标签悬停 3D 抬升、硬阴影增强；
  - 导航链接下划线生长、Logo 抖动；
  - 跑马灯横幅、背景浮动光斑。
- **标准网站流程**：
  - IntersectionObserver 驱动的滚动揭示（多方向变体）；
  - 平滑滚动、当前页导航高亮；
  - 页面切换淡出过渡；
  - 回到顶部按钮；
  - 尊重 `prefers-reduced-motion`。

### 📦 组件系统
- **更新日志页面**：独立页面，支持动态加载版本历史
- **错误页面**：404/500/503 等常见错误码友好提示
- **音乐播放器**：背景音乐 + 歌曲播放器，支持互斥播放
- **直播信息卡片**：Bilibili 直播状态实时显示
- **响应式设计**：完美适配移动端和桌面端

### 🔧 技术栈
- **核心技术**：原生 HTML/CSS/JS
- **样式框架**：Tailwind CSS（浏览器 CDN 构建）
- **图标库**：Lucide Icons
- **无需构建**：零依赖，直接打开即可运行

## 🚀 本地预览

无需安装依赖，直接用浏览器打开 `index.html` 即可。推荐起一个本地静态服务器：

```bash
# 任选其一
python3 -m http.server 5173
# 或
npx serve .
# 或
yarn start
```

然后访问 `http://localhost:5173`。
